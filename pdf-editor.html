Common questions

More detail in the full FAQ.

Can I edit text that's already in the PDF?

Not yet in this version — you can add new text anywhere on the page, but changing text that's already part of the PDF isn't supported. This is a genuinely hard problem (the original font and layout have to be preserved exactly), and we'd rather ship it properly than fake it. It's on our roadmap.

Is my PDF uploaded anywhere?

No — your file is opened and edited entirely in your browser using PDF.js and pdf-lib. Nothing is sent to any server, including ours.

Can I edit a password-protected PDF?

Not currently — encrypted or password-protected PDFs aren't supported. Remove the password first if you need to edit one.

Does this support scanned PDFs (images of text)?

You can annotate, sign, and add content on top of a scanned PDF just like any other — but since a scan is really just a picture, there's no underlying text to select or edit. Use our Image to Text or PDF OCR tool first if you need the scanned words as real, editable text.

Will my highlights and shapes be part of the actual PDF file?

Yes — everything you add is drawn directly into the saved PDF, not a separate overlay, so it will show up correctly in any PDF viewer, not just this one.

Does this work on Mac, Windows, or my phone?

Yes — it runs in any modern browser. On smaller screens the toolbar and panels adapt to a more compact layout, though precise editing is easier with a mouse or a large touchscreen.
