FAQ

Will this work on any PDF table?

Best results come from simple, grid-aligned tables. Complex multi-column layouts or scanned tables may not extract cleanly.

Does each PDF page become a separate sheet?

Yes — the output .xlsx file has one sheet per PDF page.
