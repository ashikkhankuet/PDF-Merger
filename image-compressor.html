FAQ

Does this reduce image dimensions too?

No — only compression quality changes. Width and height stay the same. Use Image Resizer for dimensions.

Does PNG actually get smaller?

PNGs are re-encoded as JPEG for maximum size reduction, since PNG's lossless format can't shrink much through quality alone. If you need to keep transparency, this isn't the right tool.
