Frequently asked questions

General questions below. Each tool page also has questions specific to that tool.

General

Is ConvertKoro really free?

Yes — every tool is free with no daily limit, no watermark, and no premium tier. The site is supported by ads, not subscriptions.

Do I need to create an account?

No. Every tool works immediately, with no sign-up, email, or login required.

Do you store or see my files?

No. All processing happens locally in your browser using client-side code. There's no server that receives, stores, or has access to your documents.

Does ConvertKoro work on mobile?

Yes, every tool is fully responsive and works on phone, tablet, or desktop browsers.

Do I need to install anything?

No installation is needed — everything runs inside a normal browser tab.

Are there watermarks?

No. ConvertKoro doesn't add watermarks to any file you download.

Does it work without an internet connection?

You need internet to load the page the first time. After that, most tools continue working offline since processing doesn't depend on a server.

Files & privacy

Is it safe to use these tools on sensitive documents?

Because nothing is uploaded, your documents never leave your device during processing — which is safer than tools that route files through a remote server.

What happens to my files after I close the tab?

Nothing is retained. Files exist only in your browser's memory while the tab is open, and are discarded when you navigate away or close it.

Are there file size limits?

We don't enforce a hard limit. In practice, very large files are limited by your own device's available memory, not by us.

Tools

Which tool should I use to reduce a scanned PDF's size?

The PDF Compressor — it works best on scanned or image-heavy PDFs, where re-encoding each page saves the most space.

Can I convert a PDF page into an editable image?

Use PDF to Image to export every page as a PNG or JPG.

How do I combine several photos into one document?

Image to PDF handles mixed formats; JPG to PDF is a faster path if everything is already a JPG.

How do I pull specific pages out of a PDF?

Use the PDF Splitter and enter the page numbers or range you need.
