How it works

  1. Paste text or upload a .txt fileWhichever is easier for what you're working with.
  2. Format, and translate if neededBasic styling options, plus optional translation to another language.
  3. Choose PDF or Word, then downloadPDF for a locked layout, Word for something still editable.

Good to know

  • This is intentionally simple — not a full word processor
  • PDF and Word creation both happen entirely in your browser
  • Translation is a separate, optional step that uses a translation service — the file itself is still built locally
  • No file size or length limit beyond what your browser can handle

FAQ

What's the difference between PDF and Word output?

PDF locks the formatting so it looks the same everywhere. Word (.docx) stays fully editable — pick whichever matches what you'll do with the file next.

Can I translate my text before downloading?

Yes — click Translate, pick a target language, and the translated version becomes what gets exported. This sends your text (not the file) to a translation service to work.

Is this like Google Docs or Microsoft Word?

No — this is intentionally simple: paste or upload text, apply basic formatting, and export. For real document editing, use Word, Google Docs, or LibreOffice directly.

Is my text uploaded anywhere?

Creating the PDF or Word file happens entirely in your browser. Only the Translate step sends your text to a translation service — and only if you use it.

Does this work on Mac, Windows, or my phone?

Yes — it runs in any modern browser on Mac, Windows, Chromebook, iPhone, or Android. No app or software to install.
