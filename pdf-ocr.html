FAQ

How is this different from PDF to Text?

PDF to Text reads real, selectable text instantly. PDF OCR is for scanned PDFs with no real text — it reads each page as an image, which takes longer.

Can this read Bangla (Bengali) text in a scanned PDF?

Yes — Bengali and English are both enabled by default, so scanned pages with Bangla text are read automatically.

Why is there a 15-page limit?

OCR is computationally heavy since it runs entirely in your browser. Longer documents are best split first.

Does this work on Mac, Windows, or my phone?

Yes — it runs in any modern browser on Mac, Windows, Chromebook, iPhone, or Android. No app or software to install.
