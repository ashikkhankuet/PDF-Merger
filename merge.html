Good to know

  • No file size or file count limit enforced by us
  • Original files are untouched — only the copy in your browser memory is combined
  • Password-protected PDFs aren't supported yet
  • Works on mobile and desktop browsers

FAQ

Is there a limit to how many PDFs I can merge?

No hard limit from us. Very large batches depend on your device's available memory since everything is processed locally.

Will the page order be preserved?

Yes — pages appear in the order your files are listed. Reorder the files first if you need a different sequence.

Does merging reduce quality?

No. Pages are copied as-is from the source PDFs, so text and images stay at their original quality.
